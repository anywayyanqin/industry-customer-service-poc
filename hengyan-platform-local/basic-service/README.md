## 可复用内容模板

- `content-service-templates.js`：通用内容服务模板与公告模板的渲染逻辑。
- `content-service-templates.css`：两类内容模板的独立样式。
- `content-template-preview.html`：两个模板的独立预览入口，不需要从具体业务页面进入。

浏览器打开 `http://127.0.0.1:4174/content-template-preview.html`，即可分别查看“通用内容服务模板”和“公告模板”。

## 已完成的内容服务业务

- 内控管理制度建设：专题正文、八个核心模块、资料区和四篇专题更新文章。
- 监管政策解读及案例分析：政策与案例聚合页、重点政策解读、规则对比、案例分析和企业行动清单。
- AI 政策智能对比：`policy-ai-compare.html`，包含新旧条款对照、差异筛选、企业影响、行动建议和模拟 AI 追问。

以上业务均从 `basic-service-home.html` 的“咨询服务”进入，文章详情支持返回所属专题、上一篇、下一篇和专题其他文章。

内容专题的“关注该专题”会保存到浏览器本地数据，并在 `index.html#workbench` 的“我关注的服务”区域展示；支持进入专题和取消关注。

培训课程中心：`training-center.html`。支持课程筛选、课程详情、章节学习和加入课程；加入后的课程会在 `index.html#workbench` 的“我的课程”区域展示并保存学习进度。

活动与人才服务统一入口：`service-hubs.html`。活动中心采用左侧主活动卡片、右侧活动列表的布局，支持关键词搜索、按活动时间或最新发布排序，并可按活动类型与行业筛选。活动卡片会先进入 `activity-detail.html`，确认活动内容后再进入 `activity-application.html` 填写预约；草稿按活动分别保存在本地，正式提交记录保存在浏览器本地的 `basicServiceActivities`。人才服务申请保存在 `basicServiceTalent`，提交后都会进入工作台的“我的活动与服务需求”。刷新页面后记录仍保留；清除浏览器网站数据后会恢复为空。

人才服务中心的项目区仅展示“专业人才输送”和“双向人员交流或实习”，两项均可直接申请；“外部专家资源库”作为独立入口放在推荐专家下方。推荐专家轮播展示职业头像、专业身份、服务方向和能力标签，通过底部横线悬停切换，并放大当前专家名片。点击卡片可查看专家详情，通过“预约咨询”进入专家预约表单；提交后仍使用 `basicServiceTalent` 与工作台联动。基础服务首页的三项人才卡片分别直达对应功能，同时提供单独的“进入人才服务中心”入口。

各业务页面统一使用基础服务下拉导航；下拉菜单首行“基础服务首页”可返回板块首页。页面内的小字路径及“返回基础服务首页”按钮也可用于返回上级页面。
- 两类模板均包含标签、适当性限制、发表时间、对应负责人、内部责任和免责声明。
- 后续内容业务通过 `ContentServiceTemplates.register()` 注册，不需要把详情结构重复写入首页 HTML。

顶部“基础服务”菜单中的咨询服务、培训课程、活动与调研、人才服务标题均可直接进入对应中心；三个活动分类入口只显示本分类内容。

工作台展示规则：顶部仅显示“我的活动”；可行性分析、人才需求及后续其他服务申请统一进入“在办业务”。

课程联动规则：培训课程中心的课程卡片先进入课程详情与目录，点击章节后进入同一页面内的视频学习视图；工作台“继续学习”直接返回该课程最近学习章节，不再跳转到另一套课程页面。

人才服务联动规则：无论从基础服务首页还是人才服务中心进入，“专业人才输送”和“双向人员交流或实习”均使用同一详情页面、同一申请入口和同一返回路径。

基础服务首页的人才服务板块设有独立的“进入人才服务中心”入口，与三项具体人才服务卡片分开。

统一导航规则：基础服务首页、工作台、咨询服务中心、培训课程中心、活动与调研中心和人才服务中心共用同一套“基础服务”下拉菜单；四个分类标题进入对应中心，具体业务进入唯一对应页面。活动中心标题横幅中的“全部活动、政策直播、行业调研、沙龙峰会”进入各自分类页。

课程路由规则：在培训课程中心内点击“套保会计实务”等课程时，即使当前已经位于培训中心，也会根据地址变化立即切换到相应课程详情与目录，不需要刷新页面。

页面层级规则：一级为“基础服务”，二级为咨询服务、培训课程、活动与调研、人才服务四个中心，三级为具体服务、课程、活动分类或内容专题。三级页面的面包屑中，二级名称必须返回对应中心，不直接返回基础服务首页；活动分类页采用“基础服务 / 活动与调研 / 具体分类”的路径。

视觉基线：以基础服务首页为标准，主要业务页面统一使用 14px 正文字号、1.6 行高、28px 主标题和 1440px 最大内容宽度；只统一基础排版参数，不改变各页面已有功能要素与业务结构。

闭环规则：一级首页进入四个二级中心，二级中心进入具体服务、课程、活动或人才三级页面；申请、预约和学习记录汇总至工作台，工作台中的“查看活动、查看申请详情、继续学习”返回对应业务内容。旧活动记录也按活动编号进入具体详情页。

以后保存新的业务页面或改变查看方式时，需要同时更新：

1. “当前原型页面”列表。
2. 页面文件或访问路径。
3. 页面当前状态。
4. 如端口或启动方式发生变化，同步修改启动说明。
